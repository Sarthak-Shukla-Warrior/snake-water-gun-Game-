# 🐍 साँप पानी बंदूक 🔫

🇬🇧 [Read in English → README.md](README.md)

बचपन का मशहूर खेल, अब रंग-बिरंगे वेब गेम के रूप में, जिसे **बच्चे आसानी से समझकर खेल सकते हैं**।
गेम **हिन्दी और English दोनों** में चलता है। ऊपर के बटन से कभी भी भाषा बदल लो।

## ✨ खास बातें
- 🌐 **दो भाषाएँ**: हिन्दी / English (एक क्लिक में बदलो, अगली बार भी याद रहेगी)
- 🦉 **चीकू उल्लू** सुझाव देता है और हौसला बढ़ाता है
- 📖 **एनिमेशन वाला "कैसे खेलें"** पेज, और नियम हमेशा नीचे दिखते रहते हैं
- 💬 हर राउंड के बाद **कारण भी बताता है** ("साँप पानी पी जाता है")
- 🗣️ चाहो तो **बोलकर सुनाने** वाला मोड (हिन्दी + English आवाज़)
- 🐣 3 लेवल: छोटा चैंपियन (आसान), सामान्य, प्रो (होशियार कंप्यूटर)
- 🦁 अपना हीरो चुनो, ⭐ सितारे जमा करो, 🏅 बैज जीतो
- 🎨 3 रंगीन थीम (गैलेक्सी, जंगल, समंदर), आवाज़ें और कॉन्फ़ेटी
- 📱 फ़ोन और कंप्यूटर दोनों पर चलता है; कीबोर्ड की `S` `W` `G` (या `1` `2` `3`)

## 📜 नियम
- 🐍 साँप 💧 पानी को पी जाता है
- 💧 पानी 🔫 बंदूक को बहा देता है
- 🔫 बंदूक 🐍 साँप को डराकर भगा देती है
- दोनों का चुनाव एक जैसा हो तो बराबरी

## ▶️ अपने कंप्यूटर पर चलाना
1. फ़ोल्डर को **VS Code** में खोलो।
2. **Live Server** एक्सटेंशन इंस्टॉल करो, फिर `index.html` पर right-click → **Open with Live Server**।
3. (या सीधे `index.html` पर double-click करो।)

असली Python वाला कंसोल गेम `python-version/snake_water_gun.py` में है।

## 🚀 GitHub पर डालना
```bash
git init
git add .
git commit -m "Snake Water Gun game"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/snake-water-gun.git
git push -u origin main
```
(पहले github.com पर `snake-water-gun` नाम की खाली repository बना लो, और `YOUR-USERNAME` की जगह अपना username लिखो।)

## 🌍 Vercel पर Deploy करना
1. [vercel.com](https://vercel.com) पर जाओ और GitHub से साइन इन करो।
2. **Add New → Project** पर क्लिक करो, फिर `snake-water-gun` को import करो।
3. सारी सेटिंग जैसी है वैसी छोड़ दो (कोई build नहीं चाहिए) और **Deploy** दबाओ।
4. तुम्हें `https://snake-water-gun.vercel.app` जैसा लाइव लिंक मिलेगा। हर `git push` के बाद यह अपने आप अपडेट हो जाएगा।
